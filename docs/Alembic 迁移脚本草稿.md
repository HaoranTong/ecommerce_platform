## 2️⃣ Redis 幂等 / 限流 PoC 实现思路

### 2.1 目标
- **幂等**：对同一业务请求（如支付回调）在短时间内只执行一次。  
- **限流**：对高频接口（如登录、下单）进行 QPS 限制，防止突发流量冲击后端。

### 2.2 技术选型
- **Redis**：使用 `SETNX`（或 `SET` with `NX`）实现一次性锁；使用 `INCR` + `EXPIRE` 实现滑动窗口计数。  
- **Python 客户端**：`redis-py`（`redis` 包）或 `aioredis`（异步）。  
- **框架**：示例基于 Flask（同步）和 FastAPI（异步）均可迁移。

### 2.3 幂等实现（示例函数）

```python
import redis
import json
import uuid
from datetime import timedelta

# 初始化 Redis 连接（请根据实际配置修改）
redis_client = redis.StrictRedis(host='localhost', port=6379, db=0, decode_responses=True)

def idempotent_execute(key: str, ttl_seconds: int = 300):
    """
    装饰器：确保同一 key 在 ttl_seconds 内只执行一次。
    key 通常由业务唯一标识（如订单号）+ 请求指纹组成。
    """
    def decorator(func):
        def wrapper(*args, **kwargs):
            # 尝试写入锁，若已存在则直接返回已缓存的结果
            lock_key = f"idempotent:{key}"
            if redis_client.set(lock_key, "LOCKED", nx=True, ex=ttl_seconds):
                # 第一次请求，执行真实业务
                result = func(*args, **kwargs)
                # 将结果序列化后写回缓存，供后续重复请求直接返回
                redis_client.set(lock_key, json.dumps(result), ex=ttl_seconds)
                return result
            else:
                # 已有缓存，直接返回
                cached = redis_client.get(lock_key)
                return json.loads(cached) if cached else {"error": "结果未就绪"}
        return wrapper
    return decorator

# 示例业务函数
@idempotent_execute(key="order:12345")
def process_payment(order_id):
    # 真实的支付处理逻辑
    return {"order_id": order_id, "status": "PAID"}
```


### 2.4 限流实现（滑动窗口）

```python
def rate_limit(key: str, limit: int, period_seconds: int = 60):
    """
    限流装饰器：在 period_seconds 内最多允许 limit 次调用。
    """
    def decorator(func):
        def wrapper(*args, **kwargs):
            counter_key = f"rl:{key}"
            # INCR 返回当前计数
            current = redis_client.incr(counter_key)
            if current == 1:
                # 第一次计数，设置过期时间
                redis_client.expire(counter_key, period_seconds)
            if current > limit:
                raise Exception(f"Rate limit exceeded: {limit} requests per {period_seconds}s")
            return func(*args, **kwargs)
        return wrapper
    return decorator

# 示例限流
@rate_limit(key="api:login", limit=10, period_seconds=60)
def login(username, password):
    # 登录业务实现
    return {"msg": "login success"}
```


### 2.5 PoC 验证步骤

| 步骤 | 操作                                                         | 预期结果                                      |
| ---- | ------------------------------------------------------------ | --------------------------------------------- |
| 1    | 启动本地 Redis（`docker run -p 6379:6379 redis:7`）          | Redis 可连接                                  |
| 2    | 编写上述装饰器并在业务接口中引用                             | 代码可运行                                    |
| 3    | 使用 `curl` 或 `ab` 并发请求同一幂等键                       | 只会有一次真实业务执行，后续返回缓存          |
| 4    | 对限流接口发送 20 次/分钟请求（limit=10）                    | 超过 10 次后返回 `Rate limit exceeded` 错误   |
| 5    | 查看 Redis 键值（`redis-cli keys "*"`）确认锁/计数键的 TTL 正常 | 锁键在 ttl 后自动失效，计数键在 period 后归零 |

## 3️⃣ Schemathesis 合约测试流程

Schemathesis 能够基于 OpenAPI/Swagger 文档自动生成请求并校验响应符合规范。下面给出 **CI 中的最小化示例**，适用于 `api-spec.md` 已发布的 OpenAPI 3.0 文档。

### 3.1 环境准备

```bash
# 1. 安装 Schemathesis（建议使用虚拟环境）
pip install schemathesis[cli]

# 2. 确保本地或 CI 环境可以访问 API 文档 URL
#    示例： http://localhost:8000/openapi.json
```


### 3.2 基本命令

```bash
# 运行所有端点的正向测试（默认 100 次随机请求）
schemathesis run http://localhost:8000/openapi.json --workers 4

# 只针对特定标签（如 "payment"）进行测试
schemathesis run http://localhost:8000/openapi.json -t payment

# 开启对响应体的 JSON Schema 验证
schemathesis run http://localhost:8000/openapi.json --validate-schema
```


### 3.3 与 CI 集成（GitHub Actions 示例）

```yaml
name: API Contract Test

on:
  push:
    branches: [ main, develop ]
  pull_request:

jobs:
  schemathesis:
    runs-on: ubuntu-latest
    services:
      redis:
        image: redis:7

      db:

          POSTGRES_USER: test

    steps:
      - uses: actions/checkout@v3
      - name: Set up Python

        with:
          python-version: "3.11"
      - name: Install dependencies
        run: |
          pip install -r requirements.txt
          pip install schemathesis[cli]
      - name: Start API (example)
        run: |
          uvicorn app.main:app --host 0.0.0.0 --port 8000 &
          sleep 5  # 等待服务启动
      - name: Run Schemathesis
        run: |
          schemathesis run http://127.0.0.1:8000/openapi.json --workers 2 --exitfirst
```


### 3.4 常见问题 & 调优

| 场景                       | 解决方案                                                     |
| -------------------------- | ------------------------------------------------------------ |
| **接口需要鉴权**           | 使用 `--auth-type=header --auth="Authorization: Bearer <token>"` 或在 `hooks.py` 中自定义 `before_send` |
| **某些端点不适合随机测试** | 在 OpenAPI 中为这些端点添加 `x-schemathesis-ignore: true`，或在 CLI 中使用 `--skip-endpoint /path` |
| **需要特定的请求体**       | 在 `hooks.py` 中实现 `@schemathesis.hooks.register`，为特定端点注入固定 payload |
| **性能瓶颈**               | 调整 `--workers`（并发数）或 `--max-response-time` 限制响应时长 |
