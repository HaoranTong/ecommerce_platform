# 全流程模型文档

## 1. 全流程主要阶段
- 需求（需求分析）
- 设计（架构与模块设计）
- 开发（编码与实现）
- 测试（单元/集成/性能/安全）
- 部署（CI/CD 与环境发布）
- 运维（监控/日志/故障恢复）
- 文档（规范/同步/归档）

## 2. 子场景细分
| 阶段 | 子场景示例 |
|------|------------|
| 需求 | REQ-001 项目启动；REQ-002 功能分析；REQ-003 非功能需求 |
| 设计 | ARCH-001 系统架构；ARCH-002 模块划分；ARCH-003 数据模型 |
| 开发 | DEV-001 文档完整性；DEV-003 数据模型；DEV-004 API 路由；DEV-007 异常处理 |
| 测试 | TEST-001 环境配置；TEST-002 单元测试；TEST-004 接口测试 |
| 部署 | DOC-004 部署文档；STATUS-003 工作归档 |
| 运维 | EMERGENCY-001 文件重建；STATUS-004 状态恢复 |
| 文档 | DOC-001 代码文档；DOC-006 工具文档 |
