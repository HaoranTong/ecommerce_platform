## ⚠️ 常见陷阱提醒

### 陷阱1：快速修复的诱惑
```
❌ 错误：看到问题 → 立即写代码
✅ 正确：看到问题 → 完成检查清单 → 再写代码
```

### 陷阱2：只测试当前修改
```
❌ 错误：只运行 pytest test_current.py
✅ 正确：运行 pytest tests/ （完整回归）
```

### 陷阱3：忽略标准文档
```
❌ 错误：凭经验判断
✅ 正确：查阅 docs/standards/ 确认
```

### 陷阱4：局部优化全局劣化
```
❌ 错误：只关注当前功能
✅ 正确：考虑对其他模块的影响
```
